# Pasta de dados (opcional)

Se existir um arquivo `shipments.xlsx` nesta pasta, o dashboard o carrega automaticamente
para quem abrir o site e ainda não tiver importado uma planilha no próprio navegador.

⚠️ Em repositórios públicos (GitHub Pages gratuito), qualquer arquivo aqui fica público.
Para dados internos, não publique a planilha: use o botão **Importar planilha** no site.
